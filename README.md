# Furtopian 사이트 + 관리 화면

- 공개 사이트: `주소/` — 지금 디자인 그대로예요. 메이커·가격표·갤러리만 관리 화면 데이터로 그려요.
- 관리 화면: `주소/admin` — PIN 입력 후 메이커·가격표·갤러리를 고치고 **저장하기**를 누르면 바로 반영돼요.
- 처음 배포하면 지금 사이트 내용(메이커 11명, 가격표 4개 탭, 갤러리 37장)이 그대로 들어가 있어요.

## 설정 순서 (행사 캘린더와 같아요)

### 1. GitHub에 올리기
1. github.com → **New repository** → 이름 `furtopian-site`, **Private** → Create.
   - 지금 GitHub Pages로 쓰는 저장소에 덮어써도 되지만, 새 저장소가 안전해요.
2. **uploading an existing file** → 압축 푼 파일·폴더를 통째로 끌어다 놓고 **Commit changes**.

### 2. Vercel에 배포하기
1. vercel.com → **Add New… → Project** → `furtopian-site` **Import**.
2. Framework Preset **Other** 그대로 → **Deploy**.

### 3. 저장소(Upstash Redis) 연결
- 프로젝트 → **Storage** 탭 → 노노라무 때 만든 Redis를 골라 **Connect Project**.
- 이 사이트 데이터는 이름 앞에 `furt:`가 붙어서 노노라무·캘린더 데이터와 섞이지 않아요.

### 4. 환경변수
프로젝트 → **Settings → Environment Variables**

| 이름 | 값 |
|---|---|
| `OWNER_PIN` | 처음 쓸 관리 PIN (숫자 6자리 이상 추천) |

넣은 뒤 **Deployments → 맨 위 ⋯ → Redeploy**.

### 5. 주소 옮기기
- 새 주소는 `furtopian-site.vercel.app` 같은 형태예요. 트위터 프로필·카카오 채널의 사이트 링크를 새 주소로 바꿔 주세요.
- 개인 도메인을 쓰고 있다면 Vercel 프로젝트 → **Settings → Domains**에 도메인을 추가하고 안내대로 DNS를 바꾸면 주소가 그대로 유지돼요.
- 다 옮긴 뒤 기존 GitHub Pages는 꺼 두세요 (저장소 Settings → Pages → None). 안 끄면 예전 사이트가 따로 남아 있어요.

## 쓰는 법

**메이커**
- 누르면 펼쳐져요: 아이콘, 이름, 스타일 설명, 포트폴리오 사진.
- **사이트에서 숨기기**: 휴재 중인 메이커를 지우지 않고 잠깐 숨길 때.
- ▲▼로 메이커 순서를 바꿔요.

**가격표**
- 위에서 탭(케모노·스트레치퍼…)을 고르고 카드를 고쳐요. 탭 추가·이름 변경·순서 변경·숨기기도 돼요.
- 포함 내용, 추가 옵션은 **한 줄에 하나씩** 적어요.
- 안내 박스: 젠타이 치수 안내 같은 분홍 박스. `**굵게**`로 강조할 수 있고, 이미지 주소를 넣으면 누를 때 그 이미지(치수표)가 떠요.
- 모서리 리본: 키구루미의 `BASE`처럼 비스듬한 띠. 비워두면 없어요.
- **복제**: 비슷한 카드를 만들 때 복제 후 고치면 빨라요.

**갤러리 / 메이커 사진**
- **📷 사진 올리기**: 폰 사진 여러 장을 한 번에 고를 수 있어요. 자동으로 줄여서 올라가요.
- **🔗 링크로 추가**: 트위터 사진 주소(`https://pbs.twimg.com/media/...`)를 한 줄에 하나씩 붙여 넣어요.
  - 트윗 주소(x.com/…/status/…)가 아니라 사진을 길게 눌러 **이미지 주소 복사**한 주소예요.
- **맨 앞에 넣기**: 갤러리는 기본으로 켜져 있어서 새 작품이 맨 앞에 와요.
- 사진 아래 ◀ ▶로 순서를 바꾸고 ✕로 빼요.

**저장**
- 무엇을 바꾸든 화면 아래 **저장하기**를 눌러야 사이트에 반영돼요. **되돌리기**는 마지막 저장 상태로 돌아가요.
- 빼낸 업로드 사진은 저장 하루 뒤 저장소에서 자동으로 정리돼요.

**설정**
- PIN 바꾸기 (바꾸면 `OWNER_PIN` 대신 새 PIN을 써요). PIN을 10번 틀리면 10분 동안 막혀요.
- **백업 파일 받기 / 불러오기**: 크게 바꾸기 전에 받아 두면 안심이에요.

폰 크롬 메뉴 → **홈 화면에 추가**로 관리 화면을 앱처럼 쓸 수 있어요.

## 고정 문구 고치기
전체 공지, 결제 안내 칩, 주문 프로세스, 커미션 안내는 `public/index.html`에 그대로 있어요. GitHub에서 그 파일을 고쳐 저장하면 자동으로 다시 배포돼요.

## 로컬 테스트 (선택)
`OWNER_PIN=1234 node dev.mjs` → http://localhost:3000 (저장은 메모리에만 돼요)
